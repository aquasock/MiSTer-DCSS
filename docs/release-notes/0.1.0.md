# MiSTer-DCSS v0.1.0

First public preview. It runs [Dungeon Crawl Stone Soup](https://crawl.develz.org/) 0.34.1, the open-source roguelike,
with its graphical tiles interface on the ARM side of a MiSTer (DE10-Nano). The game is an ordinary Linux program;
nothing is installed outside `/media/fat`. No game data is needed: the tiles, fonts and levels are part of the game.

## Install

1. Unzip `MiSTer-DCSS-v0.1.0.zip` onto the root of the MiSTer's SD card, merging with what is there. This creates
   `/media/fat/dcss` and `/media/fat/Scripts/dcss.sh`.
2. On the MiSTer press F12, choose **Scripts**, and run **dcss**.

The screen blinks as the HDMI output switches to 800x600, which your display scales to fill the screen. Quit from the
game's own menu and the launcher switches your display back to 1080p60. Full instructions are in `dcss/INSTALL.txt`
and the [README](https://github.com/aquasock/MiSTer-DCSS#readme).

You need a MiSTer with a DE10-Nano, a USB mouse and keyboard, and an HDMI display that accepts 800x600 at 60 Hz.

## What works

- The full tiles game: character creation, dungeons, saving and loading, the tutorial and hints, and the mouse and
  keyboard, with USB hotplug.
- A prebuilt level cache, so the game starts in seconds instead of spending about 90 seconds building it.
- Nothing needs `MiSTer.ini` changes and nothing outside `/media/fat` is touched.

DCSS is turn-based and only redraws when something happens. Measured at 800x600: a redraw after a move costs about 65 ms
of CPU, and the game uses about 5% of one core when idle.

## Known limitations

- No sound.
- 800x600 is the tested size.
- The software renderer uses nearest-neighbour sampling, so `tile_filter_scaling` has no effect.
- Your original HDMI mode is not saved; the launcher restores 1080p60. Set `MISTER_RESTORE_MODE` in
  `/media/fat/dcss/env.sh` if yours differs.
- Online play and DCSS's other game modes have not been tested in depth.

Original project code is GPL-2.0-or-later, and so is the package as a whole. `dcss/LICENSES/` has the license text of
every component, `dcss/ATTRIBUTIONS.md` explains what each is used for, and `dcss/SOURCES.txt` lists the exact source

[MiSTer-VCMI](https://github.com/aquasock/MiSTer-VCMI). The game is one static program, built with glibc.

Verify the download with `SHA256SUMS`.
