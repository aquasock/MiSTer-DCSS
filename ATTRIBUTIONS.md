# MiSTer-DCSS source attributions

This document records the provenance and licensing of third-party and reused
source that MiSTer-DCSS builds, patches, bundles or borrows from. It complements,
and does not replace, the copyright and license headers in individual files.

## Project code

The original code in this repository is distributed under the GNU General Public
License, version 2 or later, the same baseline as DCSS and MiSTer-VCMI. It
consists of:

- `scripts/` — the cross-build, bundling and deployment scripts and the CMake
  toolchain file.
- `src/glwrapper-sw.cc` and `src/glwrapper-sw.h` — the software renderer for
  DCSS's tiles interface. It implements DCSS's `GLStateManager` and
  `GLShapeBuffer` interfaces (declared in DCSS's `glwrapper.h`) and was written
  against those interfaces and DCSS's OpenGL implementation, `glwrapper-ogl.cc`.
  Because it is written to plug into DCSS and is linked into it, it is offered
  under DCSS's GPL-2.0-or-later terms.
- The launcher (`run.sh`) and OSD script generated by `scripts/bundle.sh`.

The full text of the GNU General Public License version 2 is in `LICENSE.txt`.
`COPYING.ZLIB` is SDL's own license text, reproduced unchanged; it applies to the
SDL code below, not to this project's original code.

The complete bundle is distributed under GPL-2.0-or-later: DCSS is
GPL-2.0-or-later, and every other component below is licensed compatibly with it
(FreeType is used under its GPL-2.0 option, not its FreeType License, because the
FreeType License is not compatible with GPL version 2).

### Relationship to MiSTer-VCMI

MiSTer-DCSS shares the SDL2 video and audio drivers of
**MiSTer-VCMI**, which are not copied into this repository: `scripts/build-deps.sh`
reads them from `../MiSTer-VCMI/sdl-driver` (or `SDL_DRIVER_DIR`). Their licensing
is described in that project's `ATTRIBUTIONS.md`: they are offered under
GPL-2.0-or-later and are compatible with SDL's zlib license when built into the
SDL library.

## Dungeon Crawl Stone Soup

The game is [Dungeon Crawl Stone Soup](https://github.com/crawl/crawl), release
0.34.1 (commit `1eebc1a2892e1c89776a0d7a10691f8dac8d9796`), fetched by
`scripts/build-crawl.sh` and not stored in this repository.

- The source code is licensed GPL-2.0-or-later (Linley Henzell, the DCSS dev team
  and contributors; see `CREDITS.txt` in the bundle's `docs/`). Some pieces
  carry other, GPL-compatible licenses: BSD, MIT, Apache-2.0, Boost and public
  domain, as listed in DCSS's `LICENSE`.
- Most tiles and artwork are released under CC0 (public domain); the licensing of
  some older pieces is more complex. DCSS keeps the details at
  <https://github.com/crawl/tiles>. The tile sheets in the bundle are packed from
  DCSS's own tile source by DCSS's own build.
- The bundle's `docs/` folder holds DCSS's `LICENSE` (as `LICENSE-DCSS`: the GPL
  text and the notice of other licenses), its `license/` folder, and this
  project's `LICENSE.txt`, `COPYING.ZLIB` and this document.

### Patches to DCSS

The files in `patches/` are modifications of DCSS and remain under DCSS's
GPL-2.0-or-later license. They are applied by `scripts/build-crawl.sh`.

- `0001-tiles-software-renderer-hooks.patch` — adds a `SWGL=y` build option that
  compiles `glwrapper-sw.cc` instead of DCSS's OpenGL wrapper and does not link
  OpenGL, disables the OpenGL wrapper when it is set, and changes the SDL window
  code so it creates no OpenGL context, takes the drawable size from the window
  size, and presents by updating the window surface.

## SDL and SDL_image

[SDL2](https://libsdl.org) 2.32.10 and SDL2_image 2.8.12 are distributed under the
zlib license (`COPYING.ZLIB` is SDL's license text and notice). Both are linked
statically. SDL2 is built with MiSTer-VCMI's video and audio drivers and its
patches (`sdl2-mister-hooks.patch` and `sdl2-resampler.patch`), which are
modifications of SDL and remain under SDL's zlib license. Altered source versions
must be plainly marked as such, and those patches are that marking.

SDL2_image is built with its bundled stb_image, nanosvg and qoi code (public
domain or MIT, zlib, and MIT); JPEG, TIFF, WebP, AVIF and JPEG XL support are off.
It decodes DCSS's PNG images.

## Runtime linked into the binary

The MiSTer's root filesystem has an old glibc (2.31), so the game is one static
executable built against the toolchain's C library.

- **glibc 2.43** (Ubuntu's `libc6-dev-armhf-cross`) — LGPL-2.1-or-later, linked
  statically. To let a user replace it, this repository contains everything needed
  to rebuild and relink the program with a different C library (the build
  scripts, the patches and the pinned upstream sources), and the glibc source is
  available from Ubuntu as the `glibc` source package.
- **libstdc++ and libgcc** (GCC 15.2, Ubuntu cross toolchain) — GPL-3.0-or-later
  with the GCC Runtime Library Exception 3.1, linked statically.

## MiSTer platform references

The framebuffer driver was written from reading the MiSTer sources; no source was
copied from them. See MiSTer-VCMI's `ATTRIBUTIONS.md` for details.

- [Main_MiSTer](https://github.com/MiSTer-devel/Main_MiSTer) (GPL-3.0) — the
  `fb_cmd*` and `video_mode` commands on `/dev/MiSTer_cmd`, and how F9 and scripts
  switch the scaler to the Linux framebuffer.
- [Linux-Kernel_MiSTer](https://github.com/MiSTer-devel/Linux-Kernel_MiSTer)
  (GPL-2.0) — `drivers/video/fbdev/MiSTer_fb.c`, which defines the `/dev/fb0`
  frame reader.

## Redistribution checklist

When publishing source or a bundle:

1. Include `LICENSE.txt`, `COPYING.ZLIB` and this document with the corresponding
   source distribution.
2. Preserve all per-file copyright and license headers in DCSS, SDL and the
   libraries above. The new files in `src/` and the SDL driver files (in
   MiSTer-VCMI) do not yet carry per-file license headers; add them before
   publishing.
3. Make the complete corresponding source available: this repository, MiSTer-VCMI
   (for the SDL drivers), and the pinned upstream releases the scripts fetch (DCSS
   0.34.1 and its submodules, SDL2, SDL2_image, zlib and libpng).
4. For a binary bundle, also ship the license texts of each bundled component: DCSS's
   `LICENSE` and `docs/license/` (installed with the game data), the
   FreeType GPL-2.0 text, the libpng and Lua licenses, the zlib license, the Bitstream
   Vera notice below, and the LGPL-2.1 (glibc) and GPL-3.0 with the GCC Runtime
   Library Exception (libstdc++, libgcc) texts; and make the glibc and GCC runtime
   sources available (Ubuntu source packages `glibc`, `cross-toolchain-base` and
   `gcc-15-cross`).
5. Do not distribute the MiSTer-Pet `fbterm-toggle` helper: it is only a test tool
   here (it is not part of the scripts or the bundle), and that project has no
   license file.

This inventory documents the repository as audited; it is not legal advice.
